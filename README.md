# EdilNova - Ristrutturazioni e Costruzioni

Sito web ufficiale di **EdilNova**, impresa edile con sede a Treviso (TV), specializzata in ristrutturazioni chiavi in mano, isolamento termico e finiture d'interni di pregio.

## 🛠️ Tecnologie Utilizzate
* **HTML5** per la struttura delle pagine.
* **CSS3 / Stili personalizzati** per il design grafico e il layout responsive.
* **JavaScript** per la gestione dinamica dei componenti.
* **Vercel** per il deployment e l'hosting in produzione.

## 📂 Struttura del Progetto
* `index.html` - Pagina Home con presentazione e servizi principali.
* `chisiamo.html` - Pagina di presentazione del team, del direttore tecnico e della filosofia di lavoro a 360°.
* `lavori.html` - Portfolio dei cantieri con galleria interattiva "Prima / Dopo".
* `contatti.html` - Modulo di contatto e informazioni utili.
* `css/` - Cartella contenente i fogli di stile.
* `images/` - Cartella contenente loghi, icone e risorse grafiche.
* `vercel.json` - File di configurazione per la gestione degli URL puliti su Vercel.
